Gemini API 키 발급

Google AI Studio에서 Gemini API 키를 발급받고 봇에 등록하는 과정을 안내합니다. AI 파티 편성 기능에 사용됩니다.

소요시간 · 약 3분난이도 · 쉬움필요한 것 · 구글 계정
Gemini API는 일정 한도 내에서 무료로 사용할 수 있습니다. 일반적인 길드 규모에서는 무료 한도로 충분합니다.
1

Google AI Studio 접속

아래 링크로 Google AI Studio에 접속합니다. 구글 계정으로 로그인하세요.

Google AI Studio 바로가기 →
[ Google AI Studio 메인 화면 ]캡처 이미지 삽입 예정
2

API 키 발급

좌측 메뉴에서 Get API key → Create API key 를 클릭합니다.
프로젝트를 선택하거나 새로 만들면 키가 즉시 발급됩니다.

[ API 키 생성 화면 ]캡처 이미지 삽입 예정
발급된 키는 화면을 닫으면 다시 볼 수 없습니다. 바로 복사해서 안전한 곳에 저장하세요.
3

봇에 키 등록하기

Discord 서버의 ⚙│봇설정 채널에서 Gemini 키 등록 버튼을 클릭하고 발급받은 키를 입력합니다.

[ 봇설정 채널 — Gemini 키 등록 화면 ]캡처 이미지 삽입 예정
Gemini 키 등록이 완료되면 레이드편성 채널의 AI 파티 편성 기능을 바로 사용할 수 있습니다.
