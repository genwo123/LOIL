STEP 2

엑셀로 길드원 명단 등록

제공하는 엑셀 양식에 레이드 목록과 길드원 정보를 채워서 웹 관리 화면에서 한 번에 업로드하는 방법을 안내합니다.

소요시간 · 길드원 수에 따라 다름난이도 · 쉬움필요한 것 · .xlsx 파일
1

엑셀 파일 준비하기

.xlsx 파일 하나에 시트 탭을 2개 만듭니다. 탭 이름에 레이드, 멤버 글자가 들어가면 자동으로 인식되고, 첫 행은 헤더로 사용합니다.

레이드 탭 — 레이드명(필수), 난이도(필수, 노말·하드·나이트메어), 요일(선택), 시간(선택, 예: 21:00), 소요시간(선택, 분 단위, 비우면 60)
멤버 탭 — 닉네임(선택, 비우면 캐릭터명 사용), 캐릭터명(필수), 권한(선택, 길드장·부길드장·공란, 길드장은 1명만)
레이드멤버
ABCDE
1레이드명난이도요일시간소요시간
2종막하드수21:0090
3세르카나이트메어
4벨가르딘노말
레이드멤버
ABC
1닉네임캐릭터명권한
2라온라온블레이드길드장
3하늘하늘소서부길드장
4별이별이서폿

예시 파일 (위: "레이드" 탭, 아래: "멤버" 탭)

2

웹 관리 화면에서 업로드하기

길드 대시보드 → 길드원 명단 → + 엑셀로 일괄 등록에서 방금 만든 파일을 선택하고 미리보기를 눌러주세요.

엑셀 업로드 화면 (예시 데이터)

3

미리보기 확인 후 등록 확정

형식이 안 맞는 행은 "건너뛴 항목"으로 따로 표시됩니다. 레이드/멤버 개수를 확인하고 이상 없으면 이대로 등록을 누르면 바로 반영됩니다.

업로드 미리보기 화면 (예시 데이터)

4

다시 올릴 때 주의할 점

같은 파일을 또 올리면(재업로드) 레이드와 멤버가 각각 다르게 처리됩니다.

레이드는 중복 체크 없이 매번 새로 추가됩니다 — 이미 올린 파일을 실수로 또 올리지 않도록 주의하세요.
멤버는 이미 등록됐거나 대기 중인 닉네임이면 자동으로 건너뛰어서 중복 등록되지 않습니다.
등록 후 각 길드원은 Discord에서 /닉네임등록으로 본인 이름을 골라 연결하면 됩니다.
