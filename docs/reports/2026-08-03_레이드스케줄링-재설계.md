# 2026-08-03 — 레이드 등록/스케줄링 재설계 (조사 + 제안)

## 배경
사용자가 지적한 문제: 지금은 레이드 하나(예: 카멘 하드)가 파티 3개가 필요하면 관리자가 슬롯 수를 수동으로 정하고(`raid_config.py`), 슬롯마다 요일/시간을 손수 입력해야 함(`raid_manage.py`). 이걸 없애고, 카멘하드/아브렐슈드/상아탑/카양겔/일리아칸 같은 **최상위 레이드만** 등록해두면 인원수·레벨에 맞춰 자동으로 파티/시간을 배정하고, 나머지 하위 레이드는 아예 스케줄링 없이 "알아서 감"으로 두고 싶다는 방향.

## 조사 결과 — 이미 있는 것 / 없는 것

**이미 있음**
- `bot/data/raids.json` → `RAID_LEVEL_MAP`: 레이드별 난이도마다 `ilvl`(요구 아이템레벨)·`size`(4/8/16인)·`duration`(기본 소요시간) 내장. 레이드 카탈로그 자체는 이미 완성된 데이터.
- `raid_config.py`의 `get_active_raids()`: 길드가 활성화한 레이드+난이도 목록, 슬롯 수·소요시간은 관리자가 수동 조정(+/- 버튼).
- `raid_manage.py`의 `SlotTimeModal`: 슬롯 하나마다 요일/시간을 관리자가 입력 → `sheets.add_raid()`로 시트에 컬럼 하나 생성.
- `party.py`: 시트 컬럼(=슬롯)에 등록된 길드원들을 서포터/딜러 균형 맞춰 파티로 묶는 AI 편성(이미 자동).
- `bot/utils/lostark_api.py` + 신규 `character_info.py`: 캐릭터 아이템레벨을 로스트아크 공식 API로 실시간 조회 가능(`get_character_item_level`). 단, **시트에 캐싱되어 있지 않고 매번 API 호출**, API 키 최대 3개 라운드로빈이라 레이트리밋 있음.

**없음 (새로 설계해야 함)**
- 슬롯 수 자동 계산 (자격 있는 길드원 수 ÷ 레이드 인원수)
- 레벨(아이템레벨) 기준으로 길드원을 레이드에 자동 배정하는 로직 — 지금 AI편성은 "이미 그 슬롯에 등록된 사람들"만 파티로 묶을 뿐, "누가 이 레이드에 갈 자격이 있는지" 판단은 안 함
- 길드원 개인별 "이번 주 가능시간" 제출 플로우 — 현재 시트 구조는 컬럼(슬롯)에 캐릭터를 적어 넣는 방식뿐, 개인의 가능 요일/시간을 저장할 곳이 없음
- 트라이(진행 중/미클리어) 표시 및 우선 스케줄링 로직

## 제안하는 새 모델

### 레이드 등록 폼 (요청하신 대로)
`레이드명 / 난이도 / 소요시간(예상) / 트라이 여부(체크박스)` — 요일·시간·분 입력 칸 전부 제거.

### 슬롯(파티 수) 자동화
등록된 레이드 하나마다: 그 난이도 `ilvl` 요건을 충족하는 길드원 캐릭터 수를 세서 `size`(4 또는 8)로 나눈 값을 파티 수로 자동 계산. 관리자가 손대는 부분 없음.

### 레벨 기반 자동 배정
자격 있는 인원을 파티 수만큼 나눠서, 서포터/딜러 비율은 지금 AI 편성 로직 그대로 재사용해 배치.

### 트라이 우선순위 — ⚠️ 여기가 설계가 더 필요한 지점
말씀하신 "개인이 소요시간을 적고, 그거 기준으로 트라이를 우선 배정" 방식이 실제로 동작하려면 아래를 정해야 합니다:
1. **길드원이 가능시간을 어디서 입력하나** — 디스코드 명령어(`/가능시간 등록`) vs 웹 폼. 지금 방향(웹 중심)상 웹이 자연스러워 보이지만 확인 필요.
2. **여러 명의 가능시간이 겹치지 않을 때 알고리즘이 뭘 할지** — 예: "가장 많은 인원이 겹치는 시간대를 자동 선택"인지, 아니면 "관리자에게 후보 2~3개를 제시하고 관리자가 최종 확정"인지.
3. **트라이 vs 일반 레이드 우선순위 충돌 시 처리** — "다른 거 다 빼고 트라이부터"라고 하셨는데, 이번 주 다른 확정된(클리어용) 일정과 시간이 겹치면 어느 쪽을 밀어낼지.

이 세 가지는 알고리즘 설계 문제라 코드보다 먼저 결정돼야 합니다.

## 제안하는 진행 순서 (수요일까지 시간 제약 고려)
1. **1단계 (이번 주 바로 가능)**: 레이드 등록 폼을 요일/시간 제거 + 레이드명/난이도/소요시간/트라이 체크로 교체, 슬롯 수 자동 계산(레벨 필터는 일단 단순 규칙으로) — `web/admin.py`, `sheets.py` 재작업.
