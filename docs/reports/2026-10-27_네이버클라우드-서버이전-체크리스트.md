# 네이버클라우드 서버 이전 체크리스트 (Micro 서버 + DuckDNS)

업체를 Hetzner에서 **네이버클라우드**로 변경(해외 카드 없음). 서버가 우분투라면 `deploy/*.sh` 스크립트는 그대로 사용.
👤 = 사용자 / 🤖 = Claude(SSH로 직접)

## 0. 알아둘 점
- Micro 서버: 한국 거주자 대상, 결제 정보 등록 시점부터 **1년 무료**, 계정당 1대, 1vCPU / 1GB / 50GB. **1년 뒤 자동 과금**(월 1만 원 안팎, 2025년 기준 자료) → 시작일을 기록해두고 만료 전에 계속 쓸지 결정/반납.
- 서버 비용만 무료일 수 있음 — **공인 IP 등 부가 상품 요금은 서버 생성 전에 콘솔에서 확인**.
- 메모리 1GB라 `setup-server.sh`가 자동으로 2GB 스왑을 만듦.
- 우분투는 **22.04 이상** 선택(코드는 파이썬 3.10 문법까지 호환 확인). 20.04(파이썬 3.8)는 피할 것.

## 1. 가입·서버 만들기 (👤) — 자세한 화면별 설명은 PDF `로일_서버이전_가이드_네이버클라우드.pdf`
- [ ] https://www.ncloud.com 가입 → 휴대폰 본인인증 → 결제 정보(국내 카드) 등록 (**등록일 기록 = 무료 1년 시작일**)
- [ ] 콘솔 Menu → All Services → Compute → Server → **서버 생성**(신규 콘솔)
- [ ] **VPC와 Subnet이 먼저 필요**(처음이면): VPC(예: 10.0.0.0/16), Public Subnet(예: 10.0.0.0/24)
- [ ] 이미지: Ubuntu Server 22.04 이상(KVM)
- [ ] 서버 타입: **Micro**(1년 무료 대상) — 목록에 없거나 예상 요금이 0원이 아니면 **만들지 말고 캡처**. 공인 IP는 서버 1대+Public Subnet일 때 생성 화면에서 할당 가능
- [ ] **새 인증키(.pem)** 생성·저장(분실 시 비밀번호 확인 불가, 채팅에 올리지 말 것)
- [ ] **ACG** 인바운드: TCP **22, 80, 443**, 소스 0.0.0.0/0 (직접 만든 ACG는 규칙이 비어 있어 반드시 추가). 80은 HTTPS 인증서 발급에 필요
- [ ] 서버 "운영중" 확인, **공인 IP** 기록(없으면 Public IP를 만들어 연결 — 요금 확인)
- [ ] 서버 관리 → **관리자 비밀번호 확인**(.pem 사용) — 비밀번호는 메모만, 채팅 금지

## 2. 내 SSH 키 등록 (👤 한 번만)
서버에 한 번 접속해서 아래 한 줄을 실행 (콘솔의 서버 접속 창, 또는 PowerShell에서 `ssh root@서버IP` 후 비밀번호 입력):
```
mkdir -p ~/.ssh && echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEu0GD8U+rIGLayBNDcB9d1qVMy3Liptf3WQzkh4iWee loil-hetzner" >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys
```
→ 이후부터 이 PC에서 Claude가 비밀번호 없이 접속 가능. (PowerShell에서 `ssh root@서버공인IP` → 관리자 비밀번호 붙여넣기)

## 3. DuckDNS (👤)
- [ ] https://www.duckdns.org 로그인 → 이름 정하기 → `current ip`에 **공인 IP** 입력 → update ip

## 4. Discord 개발자 포털 (👤)
- [ ] OAuth2 → Redirects에 `https://<이름>.duckdns.org/callback` 추가 후 저장

## 5. 알려줄 것
- 공인 **IP**, **DuckDNS 이름** (비밀번호·.pem·봇 토큰은 채팅에 붙여넣지 말 것)

## 6. 이후는 Claude (🤖)
`setup-server.sh` → 코드·`.env` 업로드 → `finalize-env.sh <도메인>`(로그인 키 자동 생성) → `install-app.sh`(venv·systemd) → `setup-caddy.sh <도메인>`(HTTPS) → `harden-ssh.sh`(내 키 접속 확인 후 비밀번호 로그인 끄기) → 접속·로그인·봇 온라인 확인 → 개발 PC 봇 종료 확인, `pull-backup.sh`로 백업 습관 안내.

## 7. 끝난 뒤 (👤)
- [ ] 🔴 개발 PC에서 봇이 켜져 있으면 끄기(같은 토큰 2곳 동시 실행 금지)
- [ ] 이 PC의 `~/.ssh/id_ed25519_loil`(비밀번호 없는 키)은 서버 정리 후 삭제/교체 권장
- [ ] 서버 무료 기간 만료일 달력에 기록
