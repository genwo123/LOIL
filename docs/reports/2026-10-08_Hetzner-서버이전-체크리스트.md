# Hetzner 서버 이전 체크리스트 (무료 서브도메인 방식)

👤 = 사용자가 직접 / 🤖 = 제가 명령어·파일을 준비해서 같이 (사용자는 붙여넣기만)
예상 시간: 처음이라 1~2시간 안팎 (추정)

---

## 0. 미리 준비할 것 (👤)

- [ ] 이메일, 결제수단(카드 또는 PayPal) — Hetzner가 가입 때 본인확인(신분증 사진 등)을 요구할 수 있음
- [ ] Discord 개발자 포털 로그인 (https://discord.com/developers/applications → 로일 앱)
- [ ] 새 Gemini API 키 (오늘 집에서 발급 예정)
- [ ] 기존 `bot/.env` 값 (봇 토큰, 로아 API 키, Discord 클라이언트 ID/시크릿)

## 1. Hetzner 가입 & 서버 만들기 (👤, 제가 화면 보며 안내 가능)

- [ ] https://console.hetzner.cloud 가입 → 이메일 인증 → 결제수단 등록
- [ ] 프로젝트 만들기 → **Add Server**
  - Location: 한국에서 가까운 곳(싱가포르가 있으면 그쪽). 없거나 비싸면 유럽도 상관없음 (봇은 지연에 둔감)
  - Image: **Ubuntu 24.04**
  - Type: 가장 싼 일반(Shared) CPU 플랜, RAM 2GB 정도 (가격은 화면에서 확인)
  - Networking: **공인 IPv4 켜기**
  - SSH key: 아래 "SSH 키 만들기" 후 공개키 등록
  - Name: `loil`
- [ ] 서버가 켜지면 **IP 주소**를 저에게 알려주기

**SSH 키 만들기 (윈도우 PowerShell)**
```
ssh-keygen -t ed25519
```
엔터만 눌러 끝까지 → `C:\Users\<이름>\.ssh\id_ed25519.pub` 파일 내용을 Hetzner SSH key 칸에 붙여넣기. (`.pub`가 아닌 파일은 절대 남에게 보내지 말 것)

## 2. 무료 서브도메인 (👤, 5분)

- [ ] https://www.duckdns.org → 구글/GitHub 계정으로 로그인
- [ ] 서브도메인 이름 정하기 (예: `loil-bot`) → add domain
- [ ] `current ip` 칸에 서버 IP 입력 → update ip
- [ ] 결과 주소: `https://loil-bot.duckdns.org` (이 주소가 아래 3~7번에서 계속 쓰임)

## 3. 서버 기본 세팅 (🤖 명령어 제공)

- [ ] 접속: `ssh root@서버IP`
- [ ] 업데이트, 방화벽(22/80/443만 허용), 일반 유저 `loil` 생성, Python venv 준비
- [ ] 폴더: `/opt/loil`, 로그 폴더 `/opt/loil/logs` **미리 만들어두기** (systemd가 로그 파일을 먼저 열기 때문에 폴더가 없으면 서비스가 시작 실패함)

## 4. 코드 올리기 (🤖 명령어 제공)

- [ ] 개발 PC에서 프로젝트를 압축해 `scp`로 업로드 (제외: `__pycache__`, `logs`, `.git`, `bot/data/backups`)
- [ ] `bot/.env`와 `bot/data/guild_settings.json`은 git에 안 올라가 있으니 따로 올리기 (테스트 데이터를 그대로 이어가려면 올림)
- [ ] 서버에서 설치: `pip install -r requirements-server.txt`
  - ⚠️ `requirements.txt`가 아니라 **`requirements-server.txt`** 를 쓸 것 — 기존 것은 개발 도구까지 들어 있고 discord.py가 구버전(2.3.2)으로 박혀 있음. 새 파일은 지금 개발 PC에서 실제로 잘 도는 버전 그대로
  - 서버 파이썬은 3.12(우분투 기본), 개발 PC는 3.14라서 설치 중 문제가 나면 그때 같이 해결

## 5. 서버용 `.env` 값 (👤 값 확인, 🤖 파일 작성)

`bot/.env`에서 **반드시 바꿀 것**:

| 변수 | 서버 값 |
|---|---|
| `WEB_BASE_URL` | `https://loil-bot.duckdns.org` |
| `DISCORD_REDIRECT_URI` | `https://loil-bot.duckdns.org/callback` |
| `SESSION_SECRET_KEY` | **무작위 긴 문자열 (아래 명령어로 생성)** |
| `DEV_SKIP_LOGIN` | `false` |
| `GEMINI_API_KEY` | 새 키 |

```
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

🔴 **`SESSION_SECRET_KEY`는 필수.** 지금 `.env`에 없어서 코드의 기본값(`dev-insecure-session-key`)이 쓰이는데, 이 값은 코드에 공개돼 있어서 누구든 가짜 로그인 쿠키를 만들어 **모든 길드 관리자 화면에 들어갈 수 있음** (이번 점검 때 제가 같은 방식으로 관리자 페이지 전체에 들어가 보고 확인함). 인터넷에 열기 전에 반드시 설정.

## 6. Discord 개발자 포털 (👤)

- [ ] 로일 앱 → OAuth2 → **Redirects**에 `https://loil-bot.duckdns.org/callback` 추가 → 저장 (정확히 같은 주소여야 함)

## 7. HTTPS 입구 만들기 — Caddy (🤖)

- [ ] Caddy 설치 후 설정 파일에 3줄:
  ```
  loil-bot.duckdns.org {
      reverse_proxy 127.0.0.1:8000
  }
  ```
- [ ] 인증서(자물쇠)는 Caddy가 자동 발급·갱신. (`deploy/README.md`의 nginx+certbot보다 단순해서 이쪽을 추천)

## 8. 상시 실행 등록 — systemd (🤖)

- [ ] `deploy/loil-bot.service`, `deploy/loil-web.service`를 `/etc/systemd/system/`에 복사 (경로 `/opt/loil`, 유저 `loil` 확인)
- [ ] `systemctl enable --now loil-bot loil-web` → `systemctl status`로 둘 다 active 확인
- [ ] 꺼져도 자동 재시작, 서버가 재부팅돼도 자동으로 켜짐

## 9. 확인 (👤 + 🤖)

- [ ] 브라우저에서 `https://loil-bot.duckdns.org` 접속 → 홈 화면
- [ ] Discord 로그인 → 길드 선택 화면
- [ ] Discord에서 봇이 온라인인지, 슬래시 명령어가 보이는지
- [ ] 실제 길드원 1~2명 초대해서 가입 코드 → 가입 신청 → 승인 → 가능시간 제출까지 한 번 (온보딩 라이브 테스트)
- [ ] 문제 생기면 `/opt/loil/logs/`와 `journalctl -u loil-web`에서 확인 (`CHANGELOG/로그_문제해결_매뉴얼.md` 참고)

## 10. 마무리 (👤)

- [ ] 🔴 **개발 PC에서 돌리던 봇은 반드시 끄기** — 같은 봇 토큰으로 두 군데에서 동시에 켜면 응답이 두 번씩 나옴
- [ ] **데이터 백업 습관**: 이제 실데이터(`guild_settings.json`)는 서버에만 있음. `storage.py`의 자동 백업은 같은 서버 디스크에 있어서 서버가 날아가면 같이 사라짐 → 주 1회쯤 `scp`로 내 PC에 내려받기 (명령어는 제가 정리해드림)

## 부록: 이번 점검에서 확인한 것 (2026-10-08)

- 공개/관리자 페이지 38개 경로 점검 → 전부 정상 (서버 로그 에러 0건). 길드 2개(실서버 1, 임시 1) 기준 읽기 전용 점검
- 봇은 실제로 켜지 않고 코드 컴파일 + 모듈 불러오기만 확인 (라이브 연결 테스트는 서버에서)
- 폰트는 프로젝트 안(`bot/assets/fonts`)에 들어 있어서 리눅스에서도 이미지 렌더링 문제 없음
- `credentials.json`(구글 서비스 계정) 검사는 결과를 무시하게 돼 있어 없어도 봇이 시작됨
- 미해결: Gemini 키 교체 (오늘 집에서), 로아 API 키는 기존 값 그대로 사용
