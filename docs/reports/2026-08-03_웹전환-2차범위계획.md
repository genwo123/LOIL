# 2026-08-03 — 관리 기능 웹 전환 2차 범위 계획

## 배경
7/31 계획(로그인 + 일정 CRUD)에서 범위를 넓혀, Discord 버튼 UI로 되어 있던 관리 기능 전체(일정·파티 편성 액션·레이드 설정)를 웹으로 옮기기로 방향 전환. 단 **봇설정(시트 URL/API 키 등록)은 이번 범위 제외**, Discord는 완전히 없애는 게 아니라 **임베드/버튼을 유지하되 상세 조작은 "웹에서 관리하기" 링크로 연결**하는 구조.

## 확인된 기술 제약
Discord 메시지 안에 실제 웹페이지를 iframe처럼 띄우는 건 불가능 (Discord Activities/임베디드 앱 SDK를 쓰면 가능하지만 별도 SDK 연동 + 심사가 필요한 무거운 작업이라 이번 범위에서 제외 — 사용자 확인 완료). 대신 Discord 임베드(카드)로 정보를 보여주고, 상세 편집은 웹 링크 버튼으로 연결하는 기존 패턴(`/g/{slug}` 편성 결과 조회와 동일한 패턴)을 그대로 확장.

## 현재 상태 점검 결과 (조사 단계)

| 영역 | 현재 상태 | 비고 |
|---|---|---|
| 웹 로그인(OAuth2) | `web/auth.py`, `web/admin.py` 코드 존재, `py_compile` 통과 | **`.env`에 `DISCORD_CLIENT_ID`/`DISCORD_CLIENT_SECRET`/`SESSION_SECRET_KEY` 없음 → 실행 불가 상태** |
| 일정 조회/추가/수정/삭제(웹) | `web/admin.py` + `admin_schedule.html` 구현됨, `bot/utils/sheets.py`의 `add_raid`/`update_raid`/`delete_raid`/`parse_all_raids` 재사용 확인 | 실제 브라우저 구동 테스트는 아직 안 함 |
| 파티 편성 액션(확정/재편성/미정처리) | 전부 `bot/cogs/party.py`의 Discord 버튼 뷰(`PartyGroupConfirmView`, `SingleRaidActionView` 등)에 있음 | 웹 이관 안 됨. 조회(`/g/{slug}`)만 웹에 있고 액션은 Discord 그대로 |
| 레이드 설정(활성화/슬롯/소요시간) | `bot/cogs/raid_config.py`, `raid_manage.py`에 Discord 명령어/버튼으로만 존재 | 웹 이관 안 됨 |
| 봇설정(시트 URL, API 키) | Discord `⚙봇설정` 채널 그대로 | **이번 범위 제외로 확정** |

## 이번 라운드에서 할 일 — 단계별 우선순위

### 1단계 (최우선, 이미 80% 되어 있음) — 일정 관리 웹 마무리
- `.env`에 OAuth2 관련 값 3개 추가 필요. **이건 사용자가 Discord Developer Portal에서 직접 발급받아야 하는 값**(Application 생성 → OAuth2 → Client ID/Secret 확인, Redirect URI를 `http://localhost:8000/callback`으로 등록) — 진행 시 안내 예정
- 로컬 `uvicorn web.main:app --reload` 구동 후 로그인 → 길드 선택 → 일정 CRUD 실제 동작 검증
- Discord `📋일정확인`/`🛡레이드편성` 채널 쪽에 "웹에서 관리하기" 링크 버튼 임베드 추가 (기존 텍스트 링크 방식과 통일)

### 2단계 — 파티 편성 액션 웹 이관
- `party.py`의 확정/재편성/미정처리 로직을 `web/admin.py`(또는 신규 `web/party.py`)로 이식
- Discord 쪽은 편성 결과 임베드 + "웹에서 확정/재편성" 버튼으로 축소

### 3단계 — 레이드 설정 웹 이관
- `raid_config.py`/`raid_manage.py`의 레이드 활성화, 슬롯/소요시간 설정을 웹 페이지로 이식

## 시간 제약 관련
수요일까지 3단계 전부는 빡빡할 수 있음 — 1단계를 먼저 끝내고 실제 진행 속도 보면서 2·3단계 범위/순서 재조정하는 걸 권장.

## 열린 질문 (착수 전 확인)
- "최초 작업(초기 설정)은 웹에서 할 수 있게"라는 언급이 있었는데, 이게 봇설정(시트 URL/API 키 등록)까지 포함하는 건지 이번 라운드에서는 확인 필요 시 재질문 — 일단 이번 범위에서는 봇설정 자체는 제외하고 진행, 필요해지면 별도로 짚기로 함.
