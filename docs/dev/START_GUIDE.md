# 🚀 로컬 테스트 시작 가이드

작업이 끝나고 "테스트해봐도 됩니다" 라고 안내받았을 때, 이 문서 하나만 보고 실행하면 됩니다.
(매 세션마다 "오늘 바뀐 부분" 섹션만 갱신됩니다.)

---

## 실행 순서 (평소 하시던 그대로)

1. VSCode에서 프로젝트 폴더 열기 (터미널이 `D:\LOIL` 프로젝트 루트인지 확인)
2. 터미널에서:
   ```bash
   python -m bot.main
   ```
   ⚠️ `python bot/main.py`로 직접 실행하면 `ModuleNotFoundError: No module named 'bot'` 에러가 납니다. 반드시 `-m bot.main` 형태로 실행해주세요.
3. 콘솔에 로그인 완료 메시지 뜨면 정상 기동.
4. Discord 서버 가서 실제로 눌러보며 확인.

> `.env`나 `requirements.txt`가 바뀐 게 아니라면 새로 `pip install` 할 필요 없습니다. 코드(cogs/utils)만 바뀐 경우 위 3단계만 하면 됩니다.

## 오늘 바뀐 부분 (2026-07-28)

**봇 재시작 필요함.**

### 1. 🛡│레이드편성 채널 — AI 시너지 추천이 실제로 옴
- `주간 전체 편성` 또는 개별 레이드 편성으로 파티를 짜면, 편성 결과 이미지가 올라온 **직후에** `🤖 AI 시너지 추천` 이라는 제목의 보라색 embed가 스레드에 추가로 옵니다.
- 확인 포인트:
  - [ ] embed가 실제로 도착하는지 (몇 초 정도 걸릴 수 있음 — 편성 결과와 동시에 안 옴, 뒤이어 옴)
  - [ ] 내용이 그럴듯한 시너지 해설인지 (엉뚱한 소리면 알려주세요)
  - [ ] Gemini 키가 없거나 실패해도 편성 결과 자체(파티 이미지)는 정상적으로 뜨는지 (추천 embed만 조용히 안 옴, 에러 메시지 안 뜸)

### 2. 버튼/문구 이름 변경 (기능은 그대로, 이름만 바뀜)
| 위치 | 이전 | 이후 |
|---|---|---|
| 🛡│레이드편성 · 주간 전체 편성 버튼 | `🤖 AI 편성` | `🤖 자동 편성` |
| 🛡│레이드편성 · 개별 레이드 편성 버튼 | `🤖 AI 편성` | `🤖 자동 편성` |
| 편성 중 안내 메시지 | `🤖 AI 파티 편성 중...` | `🤖 자동 편성 중...` |
| 시너지 추천 embed 제목 | `AI 편성 코멘트` | `AI 시너지 추천` |
| `/도움말` 파티 편성 항목 | `AI 자동 편성` | `자동 편성 + AI 시너지 추천` |
| `/정보` 주요 기능 항목 | `AI(Gemini) 파티 자동 편성` | `자동 파티 편성 + AI(Gemini) 시너지 추천` |

**바뀐 이유**: 실제 파티 배정은 그리디 알고리즘이 하고, Gemini(AI)는 배정이 끝난 뒤 시너지 해설만 덧붙이는 구조라서 "AI가 다 짜준다"는 뉘앙스를 없애고 "자동 편성 + AI가 추천/해설"이라는 걸 명확히 구분했습니다.

### 3. ⚠️ 아직 안 건드린 것 (참고만)
- `docs/*.html`(공개 웹사이트, GitHub Pages)에도 같은 종류의 "AI 파티 편성" 문구가 남아있음 — 봇 내부 문구만 먼저 바꿨고 웹사이트는 아직입니다.
- `bot/data/guild_settings.json`에 있던 API 키가 과거 git 커밋 기록에 노출돼 있던 문제 — 키 재발급은 나중에 시간 되실 때 진행하기로 했습니다. (자세한 내용은 `CHANGELOG/2026-07.md` 07/28 항목 참고)

## 오늘 바뀐 부분 (2번째 라운드) — UI/디자인 5건

**봇 재시작 필요함.** (위 1라운드와 이어서 진행한 것이라 재시작 한 번이면 둘 다 반영됩니다.)

### 1. 에러 메시지 — 눈에 보이는 변화 없음, 실패 시에만 체감
- 채널 청소/재편성/캐시초기화가 실패하는 상황을 일부러 만들기 어려우면 안 봐도 됩니다. 혹시 에러가 나면 이제 파이썬 원문 대신 "❌ OO에 실패했습니다. 잠시 후 다시 시도해주세요." 문구가 뜨는지만 확인.

### 2. 🛡│레이드편성 패널 — 버튼에 이모지 추가
- [ ] `🛡│레이드편성` 채널의 고정 패널에서 `📅 주간 전체 편성`, `🛡 개별 레이드 편성`, `⚡ 시너지 분석`, `➕ 일정 추가`, `✏️ 일정 수정`, `🗑 일정 삭제`로 전부 이모지 붙어서 나오는지 확인 (전엔 `🧹 채널 청소`만 이모지가 있었음).

### 3. ⚙│봇설정 패널 — 미완료 상태 색이 노랑으로
- [ ] 시트 URL이나 API 키를 아직 등록 안 한 상태에서 `⚙│봇설정` 패널을 보면 embed 테두리 색이 보라 대신 **노랑**으로 뜨는지 확인. 다 등록하면 기존처럼 초록.

### 4. 🔄 재편성 버튼 — 진행 메시지 추가
- [ ] 편성 결과 스레드에서 `🔄 재편성` 누르면, 바뀌기 전엔 아무 안내 없이 바로 결과가 바뀌었는데 이제 `🔄 재편성 중...` 메시지가 먼저 뜨는지 확인.

### 5. ⭐ 파티 이미지 배지 색 (가장 눈으로 직접 봐야 하는 부분)
- [ ] `내 일정 보기`로 뜨는 개인 일정 이미지에서, 딜러/서폿 역할 배지 색이 예전보다 카드 배경과 어우러지는 톤(덜 쨍한 느낌)으로 바뀌었는지 확인. 이상하게 너무 어둡거나 안 보이면 알려주세요 — 실제 렌더링은 이번에 코드로만 계산했지 직접 눈으로 못 봤습니다.

## 오늘 바뀐 부분 (3번째 라운드) — 로스트아크 API 실사용 연결

**봇 재시작 필요함.** 그리고 이번엔 **`/내정보`를 제일 먼저 테스트해주세요** — 실제 API 키로 호출해서 확인을 못 해본 코드라, 응답 필드가 문서와 조금 다르면 바로 드러날 겁니다.

### ⚠️ 먼저 확인할 것: 시트 닉네임 = 실제 캐릭터명?
- 이게 다른 길드원이 있으면 `/내정보`나 `/길드전투력`에서 그 사람만 "캐릭터를 찾을 수 없습니다"가 뜰 수 있어요. 이건 버그가 아니라 예상된 동작입니다 — 얼마나 자주 발생하는지만 확인해주시면 됩니다.

### 1. `/내정보 [캐릭터명]` — 신규
- [ ] 캐릭터명 없이 실행하면 본인 등록된 닉네임으로 조회되는지
- [ ] 초상화 이미지, 아이템 레벨, 원정대 레벨, 길드명, 각인 목록이 정상적으로 나오는지
- [ ] 존재하지 않는 캐릭터명으로 시도했을 때 에러 문구가 친절하게 뜨는지 (원시 에러 노출 없이)

### 2. `/길드전투력` — 신규
- [ ] 등록된 길드원 기준으로 평균이 뜨는지, "N명 조회" 카운트가 맞는지
- [ ] 참고: 길드원 수만큼 API를 순차 호출해서 인원이 많으면 응답이 좀 걸릴 수 있습니다 (디스코드 "생각 중" 표시로 대기 안내는 됨)

### 3. `/링크`, `/링크추가`, `/링크삭제` — 신규
- [ ] 관리자가 `/링크추가 이름:테스트 url:https://google.com`으로 등록 → `/링크`로 조회했을 때 버튼이 뜨고 클릭하면 실제로 이동하는지
- [ ] `/링크삭제`에서 이름 입력할 때 자동완성으로 등록된 링크 이름이 뜨는지
- [ ] `http://`/`https://`로 안 시작하는 URL 넣었을 때 안내 문구 뜨는지

### 4. 파티 편성 결과에 평균 전투력 텍스트 추가
- [ ] `🛡│레이드편성`에서 편성하면, AI 시너지 추천 embed와 별개로 `⚔️ 평균 전투력: 1680.xx (n/n명 조회)` 텍스트도 스레드에 오는지

### 5. 클래스 아이콘 (사용자가 직접 준비 예정)
- 이건 이번에 코드로 안 건드렸습니다 — PNG 준비되시면 `bot/assets/`에 넣고 알려주세요, 그때 연결하겠습니다.

## 오늘 바뀐 부분 (4번째 라운드) — API 401 수정 + 편성 확정 화면 통합

**봇 재시작 필요함.**

### ⚠️ 로아 API 키 재등록 필요 (직접 하셔야 함)
- 테스트 중 발견: `⚙│봇설정`에 등록된 로아 API 키가 16자짜리 잘린 값이었고, `.env`의 전역 키도 0개였습니다. 그래서 `/내정보`류 기능이 지금은 다 "캐릭터를 찾을 수 없습니다"로만 뜰 거예요(에러로 죽지는 않게 고쳤습니다).
- [ ] https://developer-lostark.game.onstove.com/ 에서 키 재발급 → `⚙│봇설정` → 로아 API 키 등록에서 **다시 전체 값**을 붙여넣어주세요 (앞부분만 복사되거나 중간에 끊기지 않았는지 확인).
- 등록 후 `/내정보`로 바로 확인 가능합니다.

### 🛡│레이드편성 — "주간 전체 편성" 확정 화면 완전히 바뀜
말씀하신 "레이드 여러 개면 저장하기·미정 처리·재편성을 각각 눌러야 하는" 문제를 없앴습니다.

- **이전**: 레이드 그룹(세르카 나이트메어/하드/노말, 종막 하드 등)마다 메시지+버튼 세트가 따로 오고, 그룹 개수만큼 저장하기를 반복 클릭.
- **이후**: 모든 레이드 이미지가 먼저 쭉 올라오고, 맨 마지막에 컨트롤 메시지 하나만 옵니다.
  - `✅ 전체 저장` — 한 번 누르면 전부 저장.
  - 드롭다운(개별로 손볼 레이드 선택) — 특정 레이드만 문제 있으면 골라서 `⏸ 미정 처리` 또는 `🔄 재편성` 가능. 이걸로 처리한 레이드는 전체 저장 대상에서 자동으로 빠지거나 갱신됩니다.

체크리스트:
- [ ] 레이드 여러 개(2개 이상) 선택해서 "주간 전체 편성" 돌렸을 때, 이미지들이 먼저 다 올라오고 컨트롤 메시지(전체 저장 버튼 + 드롭다운)가 맨 아래 하나만 뜨는지
- [ ] `✅ 전체 저장` 눌렀을 때 전부 한 번에 저장되고, 이후 주간 일정표 이미지가 오는지
- [ ] 드롭다운에서 레이드 하나 골라서 `⏸ 미정 처리` → 그 레이드가 목록에서 빠지고, 전체 저장 눌렀을 때 그 레이드는 저장 안 되는지
- [ ] 드롭다운에서 `🔄 재편성` → 새 이미지가 스레드에 추가로 오고, 전체 저장 시 새 편성 결과가 반영되는지
- [ ] 레이드가 10개 넘게 한 번에 편성되는 경우(흔치 않겠지만) 이미지가 여러 메시지로 안 깨지고 잘 나뉘어 오는지
- **개별 레이드 편성**(레이드 하나만 고르는 쪽)은 원래도 문제없던 부분이라 안 건드렸습니다 — 예전처럼 저장하기/미정처리/재편성 버튼 그대로입니다.
