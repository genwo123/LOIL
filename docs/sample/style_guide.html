그리드 칸 인터랙션 상태

가능시간 그리드·관심 레이드 그리드·전체 히트맵까지 전부 같은 "칸 클릭/드래그" 컴포넌트를 재사용합니다. 디자인 시안도 이 4가지 상태를 기준으로 주시면 바로 적용할 수 있어요.

System

핵심 흐름 2가지

화면 하나하나보다, 이 두 흐름을 먼저 이해하면 왜 화면이 이렇게 나뉘어 있는지가 보입니다.

Screens

화면 목록 (10)

실제 캡처는 다음 업데이트에서 채워 넣습니다 — 지금은 각 화면의 목적과 핵심 인터랙션만 정리했습니다.

📸캡처 예정
로그인01

/login

길드장·부길드장

Discord OAuth로 로그인하는 진입점. 관리 권한 있는 사람만 다음 단계로 넘어감.

  • "Discord로 로그인" 버튼 하나
📸캡처 예정
길드 선택02

/admin

길드장·부길드장

로그인한 사람이 관리 권한을 가진 길드가 여러 개면 여기서 하나 고름. 새 길드 만들기 진입점도 여기.

  • 길드 카드 목록 클릭
  • "새 길드 그룹 만들기" 진입
길드 홈03

/admin/{guild_id}

길드장·부길드장

이 길드의 대시보드 허브. 일정관리·시간정책·가입승인 등으로 흩어지는 시작점.

  • 하위 메뉴 카드 클릭
새 길드 만들기04

/guild/new

신규 길드장

봇을 서버에 초대하기 전에 웹에서 먼저 길드 그룹을 만들고 가입코드를 발급받음. 나중에 /길드연결로 실제 서버와 합침.

  • 길드명 입력 → 생성 → 가입코드 발급
길드 가입05

/guild/join

길드원(신규)

가입코드를 받아 기존 길드 그룹에 참가 신청. 승인 전까지는 대기 상태.

  • 가입코드 입력 → 신청
가입 승인 대기06

/admin/{guild_id}/join-requests

길드장·부길드장

가입 신청자 목록을 보고 승인/거절. 승인하면 실제 길드 데이터에 합류됨.

  • 신청자 카드별 승인/거절 버튼
일정 관리07

/admin/{guild_id}/schedule

길드장·부길드장

가장 자주 쓰는 관리자 화면. 레이드 카드 목록 + 추가/수정/삭제, 관심 인원 명단, 트라이 일정 겹침 확인까지 여기서.

  • 레이드 카드 펼쳐서 수정
  • 관심자 칩 목록(읽기 전용)
  • +공대 추가 / 삭제 확인 모달
요일별 시간 정책08

/admin/{guild_id}/time-policy

길드장·부길드장

요일마다 길드가 허용하는 활동 시간대(0~24시)를 정함. 야행성 파티가 있는 길드는 요일별로 다르게 설정 가능.

  • 요일 7개 × 시작/종료 시각 입력
길드 전체 가능시간09

/admin/{guild_id}/group-availability

길드장·부길드장

전원의 가능시간을 겹쳐서 보는 히트맵(When2meet 참고). 진할수록 가능 인원 많음. 조회 전용, 편집 불가.

  • 칸 클릭 → 아래 패널에 명단 표시
개인 가능시간 + 관심 레이드10

/me/{token}

길드원 전체

길드원이 매주 가장 많이 열어보는 화면. 드래그로 가능시간 칠하기 + 레이드별 캐릭터 체크(레벨 미달 자동 비활성) 두 섹션.

  • 드래그/클릭으로 칸 칠하기, 30분↔1시간 단위 전환
  • "저번주 불러오기"
  • 관심 레이드 섹션 접기/펼치기

v1 — 화면 구조·색·공통 컴포넌트 상태만 정리된 1차 버전입니다. 다음 업데이트에서 실제 캡처를 채우고, 신규 화면(관리자용 디스코드 딥링크 등)이 생기면 이 문서에 계속 추가됩니다.
