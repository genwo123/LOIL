로스트아크 API 키 발급

스마일게이트 개발자 센터에서 무료로 API 키를 발급받고 로일 봇에 등록하는 방법을 안내합니다.

소요시간 · 약 3분 난이도 · 쉬움 필요한 것 · 스마일게이트 계정
API 키는 외부에 노출되지 않도록 주의하세요. 봇설정 채널에서만 입력하고 Discord 일반 채널에 공유하지 마세요.
1

개발자 센터 접속 및 로그인

아래 버튼을 클릭해 로스트아크 개발자 센터에 접속합니다.
스마일게이트 계정으로 로그인이 필요합니다. 계정이 없다면 먼저 회원가입을 진행하세요.

개발자 센터 바로가기 →
[ 개발자 센터 메인 화면 ] 캡처 이미지 삽입 예정
2

약관 동의

처음 접속 시 이용약관 동의 화면이 나타납니다. 전체 동의 후 진행하세요.

[ 약관 동의 화면 ] 캡처 이미지 삽입 예정
3

API 키 발급

로그인 후 우측 상단 프로필 클릭 → 내 정보 로 이동합니다.
API 키 발급 버튼을 클릭하면 키가 즉시 생성됩니다.
발급된 키를 복사해 두세요.

키는 최대 3개까지 발급할 수 있습니다. 로일은 여러 키를 돌아가며 사용해 요청 한도를 효율적으로 늘립니다.
[ API 키 발급 화면 ] 캡처 이미지 삽입 예정
4

봇에 키 등록하기

Discord 서버의 ⚙│봇설정 채널로 이동합니다.
API 키 등록 버튼을 클릭하고 발급받은 키를 붙여넣기 합니다.
키가 여러 개라면 쉼표로 구분해 한 번에 입력할 수 있습니다.

[ 봇설정 채널 — API 키 등록 화면 ] 캡처 이미지 삽입 예정
등록 완료 후 봇이 ✅ 등록 완료 메시지를 보내면 정상 연동된 것입니다.
