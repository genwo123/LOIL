STEP 1

봇 초대 및 초기 설정

Discord 서버에 로일 봇을 초대하고 채널이 자동 생성되는 과정을 안내합니다.

소요시간 · 약 2분난이도 · 매우 쉬움필요한 것 · Discord 서버 관리자 권한
1

봇 초대 링크 접속

아래 버튼을 클릭해 로일 봇 초대 페이지로 이동합니다.
봇을 추가할 Discord 서버의 관리자 권한이 필요합니다.

로일 봇 Discord에 추가하기
[ 봇 초대 권한 확인 화면 ]캡처 이미지 삽입 예정
2

서버 선택 및 권한 승인

초대할 서버를 선택하고 권한 요청에 승인을 클릭합니다.
봇이 채널을 자동 생성하려면 채널 관리 권한이 필요합니다.

[ 서버 선택 및 권한 승인 화면 ]캡처 이미지 삽입 예정
3

채널 자동 생성 확인

봇이 서버에 입장하면 로일(LoIl) 카테고리와 아래 채널들이 자동으로 생성됩니다.

📡│공지
일정 입력 요청, 주간 갱신 알림이 올라오는 채널입니다.
🗒│일정조회
개인 일정 이미지 조회 채널입니다.
🛡│레이드편성
AI 파티 편성 및 일정 추가/수정/삭제를 하는 채널입니다.
💌│건의함
길드 문의 및 개발 건의 채널입니다.
⚙│봇설정
관리자 전용 — 로아/Gemini API 키 등록, 길드 연결 채널입니다.
⚔️│레이드설정
관리자 전용 — 운영할 레이드 활성화, 슬롯 설정 채널입니다.
채널이 생성되지 않았다면 봇을 강퇴 후 재초대하세요. 재초대 전에 로일 카테고리를 수동으로 삭제해야 합니다.
[ 채널 자동 생성 결과 화면 ]캡처 이미지 삽입 예정
4

환영 메시지 확인

📡│공지 채널에 환영 메시지와 다음 설정 안내가 표시됩니다.
이제 엑셀로 길드원 명단 등록하기로 넘어가세요.

[ 공지 채널 환영 메시지 ]캡처 이미지 삽입 예정
