# 로일(LoIl) 웹 대시보드 UI 텍스트 카탈로그

`web/templates/*.html`에 있는 사용자 노출 텍스트(제목/설명/버튼/안내문구/배지)를 페이지별로 정리한 표. 각 표 맨 오른쪽 **코멘트** 칸에 자유롭게 적어주면(고칠 문구, "이거 왜 있음?", "이 자리에 설명 하나 넣어줘" 등) 그대로 반영함. 빈 칸은 그냥 비워두면 됨 — 다 채울 필요 없음.

⚠️ 표시된 항목은 이번에 훑어보다가 발견한, 실제로 지금 상태랑 안 맞아 보이는 문구.

---
