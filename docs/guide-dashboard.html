웹 대시보드 사용법

봇 설정이 끝났다면, 실제 운영은 대부분 여기 웹 대시보드에서 이뤄집니다. 로그인 후 뜨는 화면부터 일정 관리·시너지 분석·AI 자동편성까지 한 번에 훑어봅니다.

1

로그인 & 길드 홈

사이트 홈에서 "Discord로 로그인"을 누르면 관리 가능한 길드로 자동 연결됩니다(길드가 2개 이상이면 목록에서 고르는 화면이 먼저 뜹니다).
길드 홈에는 배너, 가입/연결 코드, 그리고 각 기능으로 가는 카드들이 있습니다.

  • 가입 코드 — 관리자·길드원 누구나 볼 수 있고, 지인을 초대할 때 공유하면 됩니다. 클릭하면 클립보드에 바로 복사됩니다.
  • 봇 연결 코드 — 관리자 전용, 1회용. 봇을 초대하기 전에 웹에서 먼저 길드를 만든 경우에만 씁니다.
  • 배너 변경 — 관리자만 가능. 안 바꾸면 로일 기본 배너가 보입니다.
회색으로 흐리게 표시되고 클릭이 안 되는 카드(AI 자동편성, 가입 신청 관리)는 관리자 전용 기능이라는 뜻입니다 — 길드원 화면에서는 정상입니다.
2

일정 관리

등록된 레이드가 이름별로 접이식(아코디언)으로 묶여 나옵니다. 펼치면 그 레이드의 실제 공대(파티) 목록이 보입니다.

배지/상태의미
미정아직 요일·시간이 안 잡힌 공대
예정요일·시간이 확정된 공대
고정멤버매주 같은 인원으로 고정 진행한다는 표시(관리자가 직접 남김)
트라이아직 클리어 못 해서 진행 중인 레이드. 우선/후순위는 시간이 겹칠 때 어느 쪽을 먼저 배정할지
클리어이번 주 이미 클리어 처리된 공대(초록색 표시)
활성/비활성비활성화하면 AI 자동편성 대상에서 빠지고 "비활성화 레이드 보기" 탭으로 이동(삭제 아님)

관리자는 "+ 레이드 추가"로 새 레이드를 만들고, 각 공대에서 "+공대 추가"(사람이 더 모였을 때), "수정", "게스트"(길드원 아닌 지인 초대 인원), "클리어 처리", "삭제"를 할 수 있습니다. 길드원은 조회만 가능합니다.

3

시너지 분석

직업/각인 체크박스를 선택하면 그 조합이 어떤 시너지를 보유하고 있는지 바로 보여줍니다. "레이드에서 불러오기"로 실제 편성된 파티를 자동으로 불러올 수도 있습니다.

같은 시너지를 2명 이상이 제공하면 "겹침"으로 표시됩니다 — 로일은 "필수 시너지가 빠졌다"는 개념 대신, 이미 고른 인원 안에서 겹치는 게 있는지만 알려줍니다.

4명(파티 하나) 초과로 선택하면, 시너지가 서로 안 겹치도록 몇 개 파티로 나눌지 자동으로 추천해줍니다 — 로스트아크 시너지는 자기 파티(최대 4명) 안에서만 적용되기 때문입니다.

4

AI 자동편성

편성할 레이드를 레이드명별로 묶어서 체크하고 "자동 편성 실행"을 누르면, 배정된 인원의 가능시간을 분석해서 시간과 파티(서폿 배치 포함)를 자동으로 짭니다.

결과 화면에서 레이드별로 파티 구성, AI 시너지 코멘트, 평균 전투력을 확인할 수 있고, 원하는 레이드만 체크해서 저장하면 그때 실제로 "예정" 상태로 반영됩니다 — 저장 전까지는 아무것도 바뀌지 않습니다.

인원이 있어도 서폿이 부족하는 등 파티 구성이 안 되면 그 레이드는 저장 대상에서 자동으로 빠집니다.
5

길드원 명단

닉네임과 Discord 계정 연결 현황을 보여줍니다. "등록 완료"는 이미 연결된 사람, "미청구 명단"은 엑셀로 올렸지만 아직 본인이 Discord에서 /닉네임등록으로 연결하지 않은 사람입니다.

"길드장"·"부길드장" 배지는 이름표가 아니라 실제 권한입니다 — 이 배지가 있으면 Discord 로그인만으로 이 웹 대시보드를 관리자로 쓸 수 있습니다. 엑셀 일괄 등록 방법은 엑셀로 길드원 명단 등록 가이드를 참고하세요.

6

시간 정책 & 가능시간

요일별 시간 정책에서는 길드원이 가능시간을 제출하거나 AI가 트라이 시간을 잡을 때 허용할 시간대를 요일별로 설정합니다(평일은 늦게, 주말은 더 늦게처럼 다르게 설정 가능).

길드 전체 가능시간은 길드원 전원이 제출한 개인 가능시간을 겹쳐서 보여주는 히트맵입니다 — 진할수록 그 시간대에 가능하다는 사람이 많다는 뜻이고, 칸을 클릭하면 누가 가능한지 바로 보여줍니다. 둘 다 관리자·길드원 모두 조회 가능하고, 정책 저장만 관리자 전용입니다.

7

가입 신청 관리

길드 홈에서 가입 코드를 공유하면, 받은 사람이 /guild/join에서 Discord 로그인으로 신원을 확인하고 표시 이름·메모를 남겨 신청합니다. 관리자는 이 목록에서 실제 길드원이 맞는지 확인 후 승인/거절하고, 결과는 신청자에게 자동으로 DM 발송됩니다.

승인해도 Discord 서버 역할이 자동으로 붙지는 않습니다 — "이 사람을 길드원으로 인정한다"는 기록만 남습니다. 관리자 전용 페이지라 길드원은 이 목록을 볼 수 없습니다.
8

관리자 vs 길드원, 뭐가 다른가요

페이지관리자만 되는 것길드원도 되는 것
길드 홈배너 변경, 봇 연결코드 확인나머지 카드 전부 조회, 가입 코드 확인/복사
일정 관리레이드 추가·수정·삭제·클리어처리 등레이드 목록·상태 조회
시간 정책저장(입력칸이 비활성화됨)현재 정책 조회
길드원 명단엑셀 업로드, 미청구 삭제명단 조회
시너지 분석 / 가능시간—둘 다 동일하게 사용
AI 자동편성 / 가입 신청 관리페이지 전체접근 불가(카드가 비활성 표시)

길드장·부길드장으로 등록된 Discord 계정으로 로그인하면 자동으로 관리자 권한이 적용됩니다 — 별도로 "관리자 신청" 같은 절차는 없습니다.
