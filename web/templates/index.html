FEATURES

로일이 하는 일

엑셀 파일 하나면 바로 시작. 복잡한 설정 없이 길드 레이드를 자동화합니다.

AI 파티 자동 편성
가능 시간을 분석하고 서폿 배치·시너지를 고려해 최적의 파티를 자동 구성합니다.
시너지 파티 나누기
인원이 많아 파티가 여러 개로 나뉠 때, 시너지가 서로 겹치지 않게 최적의 조합을 추천합니다.
웹 대시보드 일정 관리
Discord 명령어 없이도 웹에서 레이드 등록·수정·공대 추가까지 전부 처리합니다.
엑셀 일괄 등록
레이드/길드원 명단을 엑셀 파일 하나로 한 번에 등록합니다. 재업로드해도 중복 걱정 없습니다.
관리자·길드원 화면 구분
길드원도 로그인해서 일정·시너지 분석을 조회할 수 있고, 수정은 관리자만 가능합니다.
가입 코드 & 공개 링크
가입 코드로 손쉽게 길드원을 초대하고, 편성 결과는 로그인 없이 링크만으로 공유합니다.
