구글 시트 템플릿 작성

제공하는 템플릿을 복사하고 길드원 가능 시간과 캐릭터 정보를 입력하는 방법을 안내합니다.

소요시간 · 길드원 수에 따라 다름난이도 · 쉬움필요한 것 · 구글 계정
1

템플릿 복사하기

아래 버튼으로 구글 시트 템플릿을 내 드라이브에 복사합니다.
복사 후 시트 이름은 자유롭게 변경해도 됩니다.

템플릿 내 드라이브에 복사하기
[ 시트 템플릿 전체 구조 ]캡처 이미지 삽입 예정
2

서비스 계정 이메일 공유

봇이 시트를 읽으려면 로일 서비스 계정 이메일을 편집자로 추가해야 합니다.
시트 우측 상단 공유 버튼 → 아래 이메일 입력 → 편집자로 설정합니다.

이 단계를 빠뜨리면 봇이 시트를 읽지 못합니다. 반드시 진행해주세요.
loil-bot@loil-project.iam.gserviceaccount.com
[ 구글 시트 공유 설정 화면 ]캡처 이미지 삽입 예정
3

길드원 탭 생성 및 가능 시간 입력

각 길드원마다 개인 탭을 만들고 가능 시간을 입력합니다.
가능한 시간대에 체크박스를 해제하면 됩니다.

빈 칸 = 가능 / 체크 = 불가 로 인식합니다.
[ 개인 탭 가능 시간 입력 화면 ]캡처 이미지 삽입 예정
4

주간 레이드 탭에 일정 입력

주간레이드 탭에 이번 주 레이드 일정을 입력합니다.
봇의 일정 추가 버튼으로도 추가할 수 있습니다.

[ 주간레이드 탭 구조 ]캡처 이미지 삽입 예정
시트 작성 후 봇설정 채널에서 시트 URL을 등록해야 연동이 완료됩니다.
