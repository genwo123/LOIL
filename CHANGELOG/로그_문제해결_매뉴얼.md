# 로그 문제해결 매뉴얼

`D:\LOIL\logs\` 안의 `bot_날짜.log` / `web_날짜.log`에서 이런 패턴을 보면 아래처럼 확인하고,
해결한 뒤에는 이 표에 새 줄로 추가해두기. (날짜, 어떤 로그였는지, 원인, 어떻게 고쳤는지)

## 자주 보이는 패턴

| 로그에 이렇게 뜨면 | 뜻 | 확인/조치 |
|---|---|---|
| `"GET /아무경로 HTTP/1.1" 404` | 존재하지 않는 주소로 요청이 옴 | 오타 링크인지, 아니면 실제로 없는 기능을 찾는 건지 확인. `favicon.ico 404`는 브라우저가 자동으로 찾는 것이라 무시해도 됨 |
| `"... HTTP/1.1" 500` | 서버 코드가 처리 중 에러로 죽음 | 바로 아래/위에 Python traceback(빨간 글씨로 여러 줄 나오는 에러 메시지)이 같이 있을 것 — 맨 아래 줄이 실제 에러 메시지 |
| `Traceback (most recent call last):` 로 시작하는 여러 줄 | 코드 에러 발생 | 마지막 줄의 `XxxError: 메시지` 부분이 핵심. 그 위의 파일 경로:줄번호가 에러 난 위치 |
| 로그가 특정 시각 이후로 뚝 끊김 | 프로세스가 죽었거나 서버가 꺼짐 | 봇/웹 프로세스가 살아있는지 확인, 다시 켜야 함 |
| `FutureWarning` / `DeprecationWarning` | 당장 고장난 건 아니고, 나중에 문제될 수 있다는 경고 | 급하지 않음. 뭘 바꾸라는 건지만 메모해두고 나중에 처리 |
