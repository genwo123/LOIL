# 2026-10 변경 기록

## 2026-10-08

### 서버 이전 준비 — 전체 점검 + Hetzner 체크리스트 + 서버용 requirements

**배경**: 상시 가동 테스트를 위해 Hetzner VPS + 무료 서브도메인(DuckDNS) 방식으로 가기로 결정. 이전 전에 "지금 사이트/봇이 이상 없이 도는지" 점검 요청.

**점검 결과(API 제외)**: 웹 서버 실제 기동 후 공개 페이지·가이드 9페이지·정적 CSS·로그인/가입 페이지·길드 2개(실서버 1, 임시 pending 1) x 관리자 11개 화면(`?as=member` 포함) 총 38개 경로를 읽기 전용으로 호출 → 전부 정상, 서버 로그 Traceback 0건. 봇은 라이브로 켜지 않고 컴파일 + cogs/web 모듈 import만 확인(이상 없음). 폰트는 `bot/assets/fonts`에 포함돼 리눅스에서도 문제없음.

**발견한 문제**: `SESSION_SECRET_KEY`가 `.env`에 없어 기본값(`dev-insecure-session-key`)으로 동작 — 점검 중 이 기본 키로 가짜 세션 쿠키를 만들어 모든 관리자 화면에 접근되는 것을 확인. 서버에 올릴 때 반드시 무작위 값 설정 필요(체크리스트 5번).

**변경(신규 파일만, 기존 파일 삭제/수정 없음)**:
- `requirements-server.txt`: 개발 PC에서 실제 동작하는 버전으로 고정한 런타임 전용 목록(discord.py 2.6.4 등). 기존 `requirements.txt`는 discord.py 2.3.2 구버전 핀 + 개발 도구 포함이라 서버 설치용으로 부적합. `pip install --dry-run`으로 충돌 없음 확인.
- `docs/reports/2026-10-08_Hetzner-서버이전-체크리스트.md`: 가입부터 서버 켜기, 도메인(DuckDNS), HTTPS(Caddy), systemd 등록, 확인, 개발 PC 봇 종료/백업까지 단계별(사용자/제가 구분).
- `CLAUDE.md`: 위 발견 사항 주의사항에 반영(credentials.json 검사는 결과를 무시해서 시작을 막지 않는다는 정정 포함).
