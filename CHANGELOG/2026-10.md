**변경**:

- 신규 라우트: `/healthz`(가동 감시용 200), `/ads.txt`(애드센스 요구 파일, 게시자 ID는 이미 페이지에 공개돼 있던 값), `/robots.txt`(관리/로그인/가입 경로는 검색 제외, 사이트맵 주소 포함), `/sitemap.xml`(홈 + 가이드 페이지, `WEB_BASE_URL` 기준 절대주소).
- `deploy/setup-caddy.sh`: 압축(gzip/zstd)과 보안 헤더(`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, 서버 이름 숨김) 추가.
- `deploy/pull-backup.sh <서버IP>` 신규: 서버의 `guild_settings.json`·건의·배너 등을 이 PC(`~/loil-backups/날짜/`)로 내려받기.

**검증**: `https://` + 기본 키 → 시작 거부 확인, `https://` + 키 설정 → 정상 시작(`https_only=True`), 로컬 http → 정상(`https_only=False`). 서버 재시작 후 `/healthz` 200, `/ads.txt`, `/robots.txt`, `/sitemap.xml`(9개 주소, `application/xml`) 정상, 42개 경로 회귀 점검 이상 0건, 로그 Traceback 0건. 스크립트 문법 검사 통과(Caddy 설정은 서버에서 실제 적용 때 확인).
