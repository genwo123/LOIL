#### `bot/utils/resolver.py` — 수정
- `is_support()`가 하이브리드 직업(홀리나이트/바드/발키리/도화가) suffix 없는 경우, `supports.json`의 `dps_aliases`에 직업명 자체(예: "발키리")가 등록돼 있으면 딜러로 판정하도록 수정. 그 외(홀리나이트/바드/도화가)는 기존처럼 기본 서폿 유지.
- 안 쓰이던 `_SUPPORT_JOBS` 상수 삭제(어디서도 참조 안 됨, 이미 `supports.json` 기반 판정으로 대체돼 있었음).
- **삭제된 코드**:
  ```python
  _SUPPORT_JOBS = {"홀리나이트", "바드", "도화가", "발키리", "기공사"}
  ```
- **이유**: `supports.json`엔 "발키리는 (폿) 명시 없으면 기본 딜러"라고 명확히 문서화돼 있는데(`rule_5`), 실제 `is_support()` 코드는 접미사 없는 발키리를 무조건 서폿으로 분류하고 있었음. 실사용 시 발키리를 접미사 없이 입력한 길드원이 파티 편성/통계에서 잘못 분류될 수 있는 실제 버그.
- 검증: `is_support('발키리')` → False(딜러), `is_support('발키리(폿)')` → True, `is_support('발키리(딜)')` → False, 홀나/바드/도화가/워로드는 기존과 동일한 결과 확인 (`resolver.py`의 `__main__` 자체 테스트 13개 케이스 모두 기대값과 일치).

#### 정정 — `bot/data/supports.json` (같은 날, 사용자 확인 후 재수정)
- 위 수정의 전제였던 `rule_5`("발키리는 (폿) 명시 없으면 기본 딜러")가 실제 게임 밸런스와 다르다는 사용자 피드백 확인. 발키리는 홀리나이트와 동일하게 **기본 서폿**이 맞고, 다만 (딜 등급 자체가 주딜러급으로 올라온 상태일 뿐) 딜 세팅은 여전히 `(딜)` 명시가 필요.
